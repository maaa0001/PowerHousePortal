Formål og læringsmål
Formålet af modulet er at lære praktiske tilgange som hjælpe studerende at udvikle web applikationer med brug af HTML, CSS, JavaScript, PHP, og en eller flere databaser. Kurset forberede studerende til at kode en full-stack applikation.

Viden
Når kurset er færdig, skulle de studerende har fået viden om:

- PHP programmeringsprog
- Object Oriented Programming (OOP)
- REST APIs
- Det MVC (Model-View-Controller) mønster
- End-point testing
- Database forbindelser
- Apache webserver

Færdigheder
Når kurset er færdig, skulle de studerende har fået færdigheder om:

- At skabe en dynamisk webapplikation
- At skabe en monolitisk eller microservice-based PHP applikation
- At skabe en PHP backend med en REST API
- At forbinde systemet til en eller flere databaser
- At deploy en online PHP website

Kompetencer
Når kurset er færdig, skulle de studerende har fået kompetencer om:

- At analyse redskaber som forbedre websites konstruktionen
- At vælge det passende teknologi til at skabe en system
